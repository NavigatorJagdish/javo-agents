## Classification Legend

- **Fully Functional**: Implemented end-to-end against real local storage/runtime/tooling and verified via automated tests.
- **Partially Functional**: Core backend/UI logic is real and tested, with optional local binaries (e.g., Ollama, Piper, whisper.cpp) or multi-screen wiring still partial or fallback-backed.
- **Mock-only**: Verified against deterministic local mock/synthetic implementations because live third-party OAuth/API credentials are absent or intentionally disabled in CI/local dev.
- **UI-only / Static**: Presentational interface or static documentation without a backing live integration.
- **Blocked by External Authorization / Signing**: Requires external accounts, platform app review, signing certificates, or hardware credentials not present in this environment.
