## Executive Summary & Physical-Device Root Cause

The `v0.1.2-alpha` hotfix addresses critical physical-device speech recognition failures reported by the owner on real Android hardware:
- **Error 13 — `ERROR_LANGUAGE_UNAVAILABLE`:** The speech manager automatically invoked `createOnDeviceSpeechRecognizer()` whenever the device supported on-device recognition, without verifying if the requested language model (Hindi / Hinglish `hi-IN`) was actually installed locally.
- **Error 11 — `ERROR_SERVER_DISCONNECTED`:** Recognizer failures triggered process crashes in speech services, and concurrent microphone ownership by `VoiceCaptureService` (declaring `FOREGROUND_SERVICE_TYPE_MICROPHONE`) violated Android audio policy during `SpeechRecognizer` binding.

---

## Key Technical Solutions

### 1. Language-Aware Recognizer Selection (Fix 1)
- **Support Checking via API 33+:** Integrates `checkRecognitionSupport()` to inspect whether requested languages (`hi-IN`, `en-IN`) are physically installed on-device.
- **Model Download Support:** Added `triggerModelDownload()` for API 34+ and system speech settings intent integration.
- **Smart Recognizer Modes:**
  - `AUTOMATIC` (Default): Checks language support; uses verified on-device engine for English or verified languages, and smoothly routes Hindi/Hinglish to the standard system recognizer to prevent Error 13.
  - `ON_DEVICE_ONLY`: Enforces strict local offline recognition; warns if offline model is uninstalled.
  - `ONLINE_ONLY`: Always uses standard system speech recognizer with full Google cloud Hindi language support.

### 2. Error 13 Recovery & Hindi Fallback (Fix 2)
- Explicitly handles `SpeechRecognizer.ERROR_LANGUAGE_UNAVAILABLE` (13) and `ERROR_LANGUAGE_NOT_SUPPORTED` (12).
- Displays clear Hindi & English diagnostic prompt:
  > *"हिंदी वॉइस मॉडल उपलब्ध नहीं है। इसे डाउनलोड करें या ऑनलाइन वॉइस रिकग्निशन चुनें।"*  
  > *(Hindi voice model is not installed on this device. Please download it or switch to Online speech recognition.)*
- Offers actionable one-tap resolution:
  - **Switch to Online Mode** (instant fallback without restarting app)
  - **Download Language Model** (triggers download request / opens speech settings)
  - **Try English Instead** (switches to `en-IN`)
  - **Dismiss**

### 3. Error 11 Recovery & Micro-Lifecycle Hardening (Fix 3)
- Explicitly catches `SpeechRecognizer.ERROR_SERVER_DISCONNECTED` (11).
- Automatically resets the broken recognizer instance, waits a 350ms backoff, and attempts a bounded retry using the standard online engine.
- Prevents infinite loops through strict session token tracking (`AtomicLong activeSessionToken`).
- Excised conflicting foreground microphone service claims during Push-to-Talk.

### 4. Honest & Actionable UI States (Fix 4)
- Never displays `Listening` until `onReadyForSpeech()` callback is confirmed.
- Uses `Connecting...` state while speech service initializes.
- Never shows `Thinking` while waiting for final audio transcript.
- Never transmits a message after speech recognition errors.
- Real-time RMS amplitude visualizer connected to actual microphone audio stream.

### 5. Voice Diagnostics & Safe JSON Export (Fix 5)
- Dedicated Voice Diagnostics screen and dialog surfacing Android version, engine type, recognizer mode, requested language, on-device language pack status, microphone permissions, waveform state, and error logs.
- Safe diagnostic export (JSON) containing zero personal audio, secret tokens, or transcripts.
