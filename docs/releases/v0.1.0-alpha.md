## What is Javo Agents?

Javo Agents is a privacy-first, locally hosted AI agent ecosystem designed to run on consumer hardware (such as 8GB RAM Windows machines) without mandatory recurring cloud subscriptions or hidden telemetry.

This initial private alpha milestone provides a complete, runnable foundation for automated multi-agent content generation, memory persistence, voice control, and cross-device approval workflows.

---

## Key Highlights & Included Subsystems

### 1. Windows Desktop Shell & Local Runtime
- **Self-Contained Installer & Portable Executable:** Electron-based desktop application packaging the React dashboard, local Python runtime, icons, and system tray menu.
- **Master Orchestrator + 29 Specialist Agents:** Deterministic goal planning, partial-approval workflows, recovery plans, and multi-agent coordination.
- **Loopback Default Binding:** Hardened to `127.0.0.1:8000` to prevent unintended local-area network exposure.
- **Hardware-Aware Adaptive Scaling:** Probes CPU cores, memory limits, and media encoders (FFmpeg, whisper.cpp) to run comfortably within 8GB RAM limits.

### 2. Android Companion App
- **Native Jetpack Compose UI:** Material Design 3 companion featuring an Approval Inbox, Task Monitor, and Push-to-Talk Voice Interface.
- **Encrypted Local Storage:** Room offline draft cache backed by hardware-backed Android Keystore tokens.
- **Local Network Pairing:** Pairing challenge-response protocol over local Wi-Fi without cloud relay dependencies.

### 3. Website & Documentation (`apps/website`)
- **24-Page Modern Web Platform:** High-performance Next.js 15 static export featuring comprehensive agent rosters, workflow documentation, setup guides, and interactive calculators.
- **Cryptographic Transparency:** Verified SHA-256 package checksums and clear private alpha test disclaimers.

### 4. Security & Privacy Hardening
- **Windows DPAPI Credential Store:** Persistent local credentials encrypted directly to the user's OS login session.
- **Core Skill Provenance Ledger:** Pinned SHA-256 integrity digests for all built-in sandbox skills; unverified or tampered plugins are strictly blocked from execution.
- **Fail-Closed Webhook Verification:** Telegram webhooks mandate constant-time secret token validation and are disabled in polling mode.
- **Honest Mock vs. Live Publishing:** Mock dispatches are distinctly marked as `SIMULATED` and never modify content assets into external published states.

## Alpha Testing Guidelines

1. **Private Repository Authentication:** As an internal alpha build, downloading packages requires logging into a GitHub account with collaborator access to `NavigatorJagdish/javo-agents`.
2. **Download Hub:** Access attached release packages from the [Private Release Hub](https://github.com/NavigatorJagdish/javo-agents/releases) under Draft Release `v0.1.0-alpha`.
3. **Windows SmartScreen Notice:** Because this alpha release is unsigned with a commercial EV certificate, Windows Defender SmartScreen will prompt during first launch. Click *"More info"* &rarr; *"Run anyway"*.
4. **Android Sideloading:** Enable *"Install unknown apps"* for your browser or file manager when testing the debug APK on physical devices or emulators.
5. **Google Play Store:** Public store listings remain closed until hardware validation and security audits are formally completed.
