## Executive Summary

`v0.1.4-alpha` delivers a comprehensive speech conversation and voice state machine hotfix for Javo Agents Android. It addresses real physical-device feedback where the voice assistant could remain frozen in "Listening" or fail to speak responses aloud. 

With this release, Javo Agents implements a deterministic 8-state voice state machine, bounded finalization watchdogs (3.5s timeout delivering partial speech), an explicit Cancel ('✕') action, lifecycle-aware `TextToSpeech` with Android `AudioManager` audio focus, direct BYOK Gemini routing with network timeout guards, and continuous Hands-Free conversation mode.

---

## Key Technical Improvements

### 1. Robust Voice State Machine
- **State Sequence:** `IDLE → CONNECTING → LISTENING → FINALIZING → THINKING → RESPONDING → SPEAKING → IDLE`.
- **Immediate Speech End Detection:** In `VoiceRecognitionManager.kt`, receiving `onEndOfSpeech()` transitions state immediately to `FINALIZING` and schedules a bounded 3.5s watchdog timer.
- **Partial Transcript Recovery:** If the system speech recognition service hangs without delivering `onResults()`, the 3.5-second watchdog triggers `onFinalizationTimeout(capturedPartial)`. If partial speech was heard, it is automatically submitted; if no speech was heard, it resets cleanly without sending empty or fabricated prompts.
- **Explicit Cancel Action:** Users can tap the Cancel ('✕') button at any time during `LISTENING` or `FINALIZING` to instantly abort voice capture and release audio hardware.
- **Concurrency & Idempotency Guard:** `MainViewModel.kt` enforces atomic execution via an `AtomicBoolean` guard (`isProcessingVoiceCommand`), preventing duplicate executions if manual stop and recognition callbacks arrive simultaneously.

### 2. Spoken AI Audio Responses via Lifecycle TTS
- **Audio Focus Management:** `VoiceTtsManager.kt` acquires `AudioManager.AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK` prior to speaking and releases audio focus immediately on completion, error, or user interruption.
- **Fail-Closed Guarantee:** If TTS synthesis fails or voice data is missing, `speak()` returns `false` and immediately resets `_isSpeaking.value = false`, ensuring the UI never falsely displays `Speaking`.
- **User Interruption:** Tapping the FAB button while Javo is speaking (`SPEAKING` state) immediately halts audio playback via `stopSpeaking()`.
- **Speech Rate & Voice Selection:** Configurable speech rate (0.8x to 1.5x) persisted in encrypted Keystore, with voice selection prioritizing female/natural voices across Hindi (`hi-IN`), Indian English (`en-IN`), and US English (`en-US`).

### 3. Direct AI Provider Routing with Timeout Guard
- **Phone-Only Independence:** Direct BYOK Gemini routing functions seamlessly in Standalone mode without Windows.
- **25-Second Timeout Guard:** All mobile AI queries are wrapped in a 25-second timeout (`withTimeoutOrNull(25_000L)`) to prevent UI freezes on flaky mobile networks.
- **Unconfigured Advisory:** Clearly indicates if a Gemini API key is missing rather than stalling in silence.

### 4. Natural Two-Way Conversation Modes
- **Tap to Talk (`TAP_TO_TALK`):** Traditional push-to-talk turn. User taps mic, speaks, receives answer and spoken voice, and the assistant returns to `IDLE`.
- **Hands-Free Conversation (`HANDS_FREE`):** Continuous conversational loop. Upon TTS `onDone()` completion, Javo pauses for a 650ms acoustic silence guard (to prevent picking up speaker reverberation) and automatically reopens listening for the user's next question.
