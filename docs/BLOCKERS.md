# Known Blockers & Environment Notes

| ID | Area | Description | Workaround / Next Step |
| :--- | :--- | :--- | :--- |
| **BLK-01** | `apps/android/` Local SDK | `java` (JDK 17), `gradle`, and Android SDK (API 35) are not installed on this local Windows workstation. Validation uses GitHub Actions `CI — Android Companion` on PR #1 (`fix/android-ci-and-production-hardening`). | Install Android Studio / JDK 17 locally if offline Android builds are needed; otherwise rely on GitHub Actions CI. |
| **BLK-02** | External APIs & Credentials | No live Facebook, Instagram, YouTube OAuth client credentials, Telegram `@BotFather` token, Gemini API key, or local Ollama daemon are pre-configured in CI/dev. | All connectors and AI routing degrade cleanly to deterministic `$0` fallbacks and `MockConnector` (`mode="mock"`). Configure credentials locally via Settings -> AI Providers / Social Accounts to exercise live endpoints. |
| **BLK-03** | Release Signing & Store Review | No Windows Authenticode code-signing certificate, Android release upload keystore, or Google Play Developer account credentials are stored in this repository. | Packaged Windows executables and release Android bundles remain unsigned verification artifacts until owner configures signing secrets per `docs/release/RELEASE_AND_SIGNING_GUIDE.md`. |
| **BLK-04** | Optional Voice Binaries (`piper`, `whisper-cli`) | `piper` TTS and `whisper-cli` STT binaries are not pre-bundled in the repository. | Voice `/tts` generates valid non-empty PCM WAV audio locally and `/transcribe` validates WAV headers/durations while clearly reporting engine status when binaries are absent. |
